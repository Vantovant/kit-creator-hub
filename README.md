# Vanto Zazi Mail

Vanto Zazi Mail is a creator-first email marketing platform designed to help creators, educators, and entrepreneurs build audiences, send powerful email campaigns, and automate communication — without complexity.

This project is inspired by modern email platforms but is being developed as a custom, independent system tailored for private use and future expansion.

## Core Features (Current & Planned)

- Email broadcast creation with visual editor
- Subscriber management (import/export)
- Segmentation and tagging
- Automation workflows
- Analytics dashboard
- Template library
- Dark mode dashboard
- Third-party integrations (planned)

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Bun
- Recharts
- Custom UI components

## Project Status

This repository represents the **foundation stage** of the platform.
UI and architecture are in place.
Backend services and email delivery will be added in later phases.

## Vision

Built in Africa.
Designed for creators.
Powered by clarity, automation, and ownership.
