# Vanto Zazi Mail

**Creator-first email marketing platform built for Africa.**

---

## Overview

Vanto Zazi Mail is a private email marketing operating system designed for creators, educators, and network marketing teams. It combines audience management, email automation, AI-powered knowledge base, productivity tools, and campaign reply management in a single dashboard.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React 18, TypeScript, Vite 5, Tailwind CSS v3 |
| UI | shadcn/ui (Radix primitives), Lucide icons, Recharts |
| Backend | Lovable Cloud (Supabase) — PostgreSQL, Edge Functions, Storage |
| Email | Resend |
| AI | Lovable AI (Gemini / GPT models) |
| Auth | Supabase Auth (email/password) |

## Core Features

- **Email Broadcasts** — Visual editor, segment targeting, scheduling, A/B testing
- **Email Sequences** — Multi-step drip campaigns (e.g. 90-Day Momentum Run with 107 steps)
- **Subscriber Management** — Import/export, tagging, engagement scoring, APLGO fields
- **Automations** — Event-driven workflows with triggers and step chains
- **Reply Inbox** — Campaign-reply-only workspace with 4-tier matching, intent tags, and Plan Hub integration
- **Knowledge Base** — Upload documents, AI-powered RAG search (Zazi Copilot)
- **Plan Hub** — Tasks, reminders, meetings, calendar, notes, voice input, Command Bar (⌘K)
- **Analytics** — Email performance metrics, engagement distribution, delivery charts
- **Templates** — Reusable email templates with categories
- **Segments** — Dynamic audience filtering
- **Forms** — Public signup forms for sequences and general subscriptions
- **Integrations** — Marketplace UI (backend connections planned)
